# Toggle Through TODO Statuses On Current Block

On an older version of [Logseq](https://logseq.com/), I used to be able to start
a block with `TODO` or `DONE` and it would translate to the TODO checkbox
element. I liked the ergonomics of this.

Then I migrated to the newer version of Logseq and the TODO element was reworked
in a way that added more friction. You have to type the `/todo` slash command
and hit `Enter` while that command is focussed. Then toggling the TODO status
requires a click to open the menu and then pick the right option from the menu.

I put up with the new flow, but I was excited to find that the whole thing is
much easier to control by toggling through the main TODO states with
`Cmd+Enter`. Tapping that keybinding in succession will cycle through `Todo`,
`Doing`, `Done`, and _None_.

My new flow is now:

1. Type out the substance of a block (e.g. "Revisit this retro session
   bfc5b4be-4759-4082-8a29-b61972403ec1")
2. Toggle it to `Todo` with `Cmd+Enter`
